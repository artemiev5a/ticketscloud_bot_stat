# Ticketscloud Statistics Bot

Telegram-бот получает статистику из Ticketscloud по ключу каждого организатора.

## Запуск

1. Скопируйте `.env.example` в `.env` и укажите только `TELEGRAM_BOT_TOKEN`.
2. Установите зависимости: `pnpm install` (или `npm install`).
3. Запустите: `pnpm dev` для разработки или `pnpm build && pnpm start` для продакшена.

Не записывайте ключ Ticketscloud в `.env`: организатор отправляет его боту в личном чате командой `/setkey ВАШ_КЛЮЧ` или через кнопку «Указать API-ключ». Ключ хранится только в памяти работающего процесса и не передаётся другим пользователям.

## Отчёт

Команда `/stats` запрашивает все страницы `GET https://ticketscloud.com/v2/resources/orders` со статусом `done`. По умолчанию отчёт охватывает текущие сутки от `00:00:00` до следующих `00:00:00` в UTC. Сумма берётся из документированного поля заказа `values.full`, а число проданных билетов — из массива `tickets`.

Для совпадения с отчётом личного кабинета выбирайте в нём тот же период UTC и показатель полной суммы завершённых заказов. Если кабинет учитывает возвраты или использует другую дату продажи, правила этого отчёта нужно согласовать с поддержкой Ticketscloud: опубликованный endpoint списка заказов фильтрует только по `created_at`.
